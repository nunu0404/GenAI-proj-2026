# 예시 강의 시나리오 3개

각 시나리오는 실제로 말하거나, 발표자 화면의 텍스트 입력에서 **발화로 입력**으로 한 줄씩 넣어 재현할 수 있습니다. `▶`는 생성 요청, `✕`는 생성되지 않아야 하는 발화, `?`는 입력 보완이 기대되는 발화입니다.

## 1. 머신러닝 기초: 과적합 (청중: 대학 신입생)

1. 오늘은 모델이 데이터를 어떻게 배우는지 이야기하겠습니다.
2. 과적합은 학습 데이터에 지나치게 맞춰져서 새로운 데이터에는 잘 대응하지 못하는 현상입니다.
3. 그래서 연습 문제 점수는 높은데 실제 시험 점수는 낮게 나오는 일이 생깁니다.
4. ▶ 다음 슬라이드에서는 과적합을 시험 문제를 외운 학생에 비유해서 설명하겠습니다.
   - 기대: 제목과 핵심 문장 2~3개가 먼저 미리보기에 나타나고, 기출문제만 외운 학생이 새 문제 앞에서 당황하는 일러스트가 이어서 도착합니다.
5. (이미지 생성 중에 계속) 이걸 막으려면 검증 데이터로 중간중간 확인해야 합니다.
6. ✕ 다음 슬라이드를 보시면 학생 그림이 있습니다. (장 넘김 발화)
7. ▶ 다음 장에는 학습 데이터와 검증 데이터를 나누는 방법을 보여주세요.
8. ? 다음 슬라이드에서는 아까 말한 거 설명할게요. → 입력 보완 카드에 `조기 종료`를 입력하고 생성

## 2. 통계학 입문: 표본과 편향 (청중: 고등학생)

1. 표본은 전체 집단에서 일부를 뽑은 것입니다.
2. 국을 끓이고 한 숟가락 맛을 보는 것과 같습니다. 국을 잘 저어야 한 숟가락이 전체 맛을 대표하죠.
3. ▶ 슬라이드를 만들어 주세요. (잠시 멈춤) 주제는 표본 편향입니다. — 두 개의 STT 구간으로 나뉘어도 한 건으로 처리됩니다.
4. ✕ 여러분이 “다음 슬라이드에서는 평균을 설명하겠습니다”라고 말하면 시스템이 슬라이드를 만듭니다. (인용)
5. ▶ 다음 슬라이드에서는 정확한 정규분포 그래프로 표준편차를 보여주세요.
   - 기대: 정확한 그래프는 생성 이미지로 그리지 않고 개념적 비유로 대체하며, 발표자 화면에 `precision_warning`이 표시됩니다. (LLM 출력에 의존하므로 실제 API로는 아직 확인하지 않음)
6. ✕ 다음 슬라이드는 만들지 마세요. 칠판에 그려 보겠습니다. (부정)

## 3. 세포생물학: 세포는 작은 공장 (청중: 대학 신입생)

1. 세포를 하나의 공장으로 생각해 봅시다.
2. 핵은 설계도를 보관하는 본사 사무실이고, 리보솜은 조립 라인입니다.
3. ▶ 다음 슬라이드에서는 미토콘드리아를 설명하겠습니다.
   - 기대(맥락 효과): 직전 발화의 공장 비유를 이어 받아 '발전소' 같은 비유가 나오는지 확인합니다. A/B 평가 대상이며, 실제 API로는 아직 확인하지 않았습니다.
4. ▶ 다음 장에는 골지체를 택배 포장 센터에 비유해서 보여주세요.
5. ▶ 다음 슬라이드에서는 세포막을 공장 출입문 경비원에 비유해서 설명하겠습니다.
   - 대기열 확인: 4와 5를 연달아 말하면 하나는 실행되고 하나는 대기합니다. 대기 중인 요청은 취소할 수 있습니다.
6. 생성 중 **생성 취소**를 누릅니다 → 늦게 도착한 결과는 무시되고 다른 장은 바뀌지 않습니다.
