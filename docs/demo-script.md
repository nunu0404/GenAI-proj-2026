# 3분 시연 대본

준비: 백엔드와 프런트엔드를 실행하고, 실제 API 모드라면 `.env`에 키를 설정합니다. 세션 “머신러닝 기초 / 대학 신입생”을 만들고, 청중 화면을 두 번째 모니터(또는 창)에 띄웁니다. mock 모드로 시연할 때는 화면 상단의 **MOCK 배지**를 그대로 보여 주고, 실제 생성이 아니라고 말로도 밝힙니다.

| 시간 | 화면/동작 | 말할 내용 |
|---|---|---|
| 0:00–0:20 | 발표자 화면 전체 | “NextSlide는 강의 중 다음 장을 말로 요청하면 설명 이미지가 들어간 웹 슬라이드를 만들어 주는 시스템입니다. 왼쪽이 지금 청중이 보는 장, 오른쪽이 다음 장 미리보기와 자막입니다.” |
| 0:20–0:40 | **● 마이크 시작** | (강의하듯) “과적합은 학습 데이터에 지나치게 맞춰져서 새로운 데이터에는 잘 대응하지 못하는 현상입니다.” → 자막이 임시(회색)에서 확정으로 바뀌는 것을 가리키고, 이 발화로는 아무것도 생성되지 않는다는 점을 보여 줍니다. |
| 0:40–1:10 | 요청 발화 | “다음 슬라이드에서는 과적합을 시험 문제를 외운 학생에 비유해서 설명하겠습니다.” → 로그의 `생성 요청 확정`, 작업 카드의 `기획 중 → 텍스트 준비 → 이미지 생성 중`. “제목과 핵심 문장이 먼저 미리보기에 나오고, 그림은 생성 중입니다. 청중 화면은 아직 바뀌지 않았습니다.” |
| 1:10–1:30 | 생성 중 계속 말하기 | “그래서 검증 데이터로 중간중간 확인해야 합니다.” → 이미지 생성 중에도 자막이 계속 올라오는 것을 보여 줍니다. |
| 1:30–1:50 | 준비 완료 → `→` 키 | “준비 완료 표시가 뜨면 다음 장으로 넘깁니다.” → 청중 화면이 짧은 페이드와 함께 동기화됩니다. 이미지 안에 글자가 없고, 제목과 본문은 웹 텍스트로 따로 배치된다는 점을 설명합니다. |
| 1:50–2:15 | 오동작 방지 | “여러분이 ‘다음 슬라이드에서는 평균을 설명하겠습니다’라고 말하면 슬라이드가 생깁니다.” → `인용된 지시로 판단해 생성하지 않음`. 이어서 “다음 슬라이드는 만들지 마세요.” → `부정 지시`. |
| 2:15–2:35 | 모호한 요청과 복구 | “다음 슬라이드에서는 아까 말한 거 설명할게요.” → `입력 보완 필요` 카드에 “검증 데이터”를 입력하고 생성합니다. 음성 인식이 실패해도 텍스트 입력의 **현재 입력으로 생성**으로 복구할 수 있다고 덧붙입니다. |
| 2:35–2:50 | 저장·재발표 | 새로고침 → 같은 세션이 그대로 복원됩니다. 홈의 저장된 세션 목록에서 다시 열 수 있습니다. |
| 2:50–3:00 | 성능 지표 패널 | “요청 확정부터 준비 완료까지 걸린 시간을 표본 수와 함께 기록합니다. 실제 발화가 끝난 시각은 알 수 없어서, VAD 추정값을 따로 표시합니다.” |

### 화면이 하나일 때 (노트북 화면을 그대로 프로젝터에 띄우는 경우)

**전체 화면 발표**를 누르면 마이크가 함께 켜집니다. 발표 중에는 전체 화면을 나오지 않고 `M`(마이크), `→`(다음 장)으로 진행합니다. 새 장이 준비되면 오른쪽 아래에 짧은 알림이 뜹니다. 화면이 두 개라면 청중 화면 창을 프로젝터로 보내고, 노트북에서는 발표자 화면을 그대로 쓰면 됩니다.

### 시연 중 문제가 생기면

- 마이크 권한이 거부되면 화면에 원인이 표시됩니다. 이때는 텍스트 입력의 **발화로 입력**으로 같은 대본을 넣어 계속합니다.
- 이미지 생성이 실패하면 현재 장은 그대로이고, 미리보기에서 **재시도** 또는 **이미지 없이 완료**를 누릅니다.
